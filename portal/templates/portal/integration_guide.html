Connect your platform

Use these API endpoints and examples to display posts on your existing website. The code below already contains this project’s read-only API key and this server’s URL.

Only published posts and scheduled posts whose publication time has arrived are returned. Your website controls its design, article routes and SEO rendering.
API endpoints & response

Required header: X-API-KEY. No login cookie or bearer token is required.

{{ integration_examples.curl }}

List response example (abbreviated; example values):

{
  "project": "Your project",
  "blogs": [{
    "id": 1,
    "slug": "your-post-slug",
    "title": "Your post title",
    "excerpt": "Short introduction",
    "content": "<p>Main post content</p>",
    "cover_image_url": "https://your-platform.example/storage/image.jpg",
    "cover_image_alt": "Image description",
    "author_name": "Author",
    "sections": [{
      "id": 1,
      "text_content": "<p>Section content</p>",
      "image_url": null,
      "image_alt": "",
      "image_caption": ""
    }],
    "seo": {
      "title": "SEO title",
      "description": "SEO description",
      "canonical_url": null,
      "robots": {"index": true, "follow": true}
    }
  }],
  "meta": {"current_page": 1, "last_page": 1, "per_page": 12, "total": 1}
}

The single-post endpoint returns {"project": "…", "blog": {…}}. Set page from 1 and per_page from 1–100. Use meta.current_page and meta.last_page for navigation.

Images: use the absolute cover_image_url and section image_url. Content: the API sanitizes content and section text_content. Escape ordinary text such as titles and excerpts. SEO: apply seo metadata on individual pages; canonical URLs and structured data require a configured public URL or enabled hosted blog.

401: invalid key. 404: unknown/unpublished slug. 400: invalid pagination or rate-limited request. Browser CORS: verify your exact website origin in Analytics & Search → Sitemap, or fetch on your server. Keep website/CDN caches in sync when posts change or are unpublished.

React / Next.js

Shopify

API integration on your existing store. Add a Custom Liquid section to a dedicated page template, then paste this HTML/JavaScript example. Verify the exact storefront origin in Analytics & Search → Sitemap first so browser requests can pass CORS.

{{ integration_examples.shopify }}

This displays published posts and opens the selected post on the same page using ?twpost=slug. It fetches content from WritePost; it does not create native Shopify articles. Preview on your theme and check navigation before publishing.

Browser-rendered content does not set Shopify’s server-generated per-post SEO metadata or sitemap entries. For server-rendered content within your storefront, your developer can build a Shopify app proxy. That app connector is not included.

WordPress

Easiest setup: download the starter plugin, upload it via Plugins → Add New → Upload Plugin, then activate it. In Settings → WritePost enter the Platform URL and project API key shown above. Add a Shortcode block to a page:

[writepost_posts]
Download WordPress starter plugin

Developer example: this PHP request/body can run inside a shortcode callback in your own plugin. It reads the list and returns escaped titles/excerpts. For complete listing/detail navigation and images, use the downloadable plugin.

Requests run on WordPress’s server, so browser CORS is not required. The shortcode reads live posts; it does not import native WordPress posts or set per-post canonical URLs, metadata or sitemap entries. Configure your theme and SEO integration separately.
